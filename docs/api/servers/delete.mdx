## Endpoint

<Card>
  <code>DELETE https://api.superbox.ai/api/v1/servers/:name</code>
</Card>

## Authentication

<Tabs>
  <Tab title="Required">
    This endpoint requires authentication. You must be the server owner.
    <Warning>
      Only the server owner can delete a server. This action is **irreversible**.
    </Warning>
  </Tab>
</Tabs>

## Path Parameters

<ParamField path="name" type="string" required>
  Unique server identifier to delete. **Example:** `weather-mcp`, `my-test-server`
</ParamField>

## Response

<ResponseField name="status" type="string">
  `"success"` on success, `"error"` on failure
</ResponseField>

<ResponseField name="message" type="string">
  Deletion confirmation message
</ResponseField>

## Examples

<CodeGroup>
```bash cURL
curl -X DELETE "https://api.superbox.ai/api/v1/servers/my-test-server" \
  -H "Authorization: Bearer $SUPERBOX_API_TOKEN"
```

```javascript JavaScript
async function deleteServer(serverName) {
  const response = await fetch(
    `https://api.superbox.ai/api/v1/servers/${serverName}`,
    {
      method: 'DELETE',
      headers: {
        'Authorization': `Bearer ${process.env.SUPERBOX_API_TOKEN}`
      }
    }
  );

  const result = await response.json();

  if (result.status === 'success') {
    console.log(result.message);
  } else {
    console.error(`Failed to delete: ${result.detail}`);
  }

  return result;
}

await deleteServer('my-test-server');
```

```python Python
import requests
import os

def delete_server(server_name):
    url = f"https://api.superbox.ai/api/v1/servers/{server_name}"
    headers = {
        'Authorization': f'Bearer {os.getenv("SUPERBOX_API_TOKEN")}'
    }

    response = requests.delete(url, headers=headers)
    result = response.json()

    if result['status'] == 'success':
        print(result['message'])
    else:
        print(f"Failed: {result['detail']}")

    return result

delete_server('my-test-server')
```

```go Go
package main

import (
"encoding/json"
"fmt"
"net/http"
"os"
)

func deleteServer(name string) error {
url := fmt.Sprintf("https://api.superbox.ai/api/v1/servers/%s", name)

req, _ := http.NewRequest("DELETE", url, nil)
req.Header.Set("Authorization", "Bearer "+os.Getenv("SUPERBOX_API_TOKEN"))

client := &http.Client{}
resp, err := client.Do(req)
if err != nil {
return err
}
defer resp.Body.Close()

var result map[string]interface{}
json.NewDecoder(resp.Body).Decode(&result)

if result["status"] == "success" {
fmt.Println(result["message"])
} else {
fmt.Printf("Failed: %v\n", result["detail"])
}

return nil
}

func main() {
deleteServer("my-test-server")
}
```

## Before You Delete

<AccordionGroup>
  <Accordion title="Consider Deprecation Instead" icon="archive">
    Instead of deleting, you can mark your server as deprecated so existing users
    can migrate gracefully:

    ```javascript
    // Update description to indicate deprecation
    await fetch(url, {
      method: 'PUT',
      headers,
      body: JSON.stringify({
        description: 'DEPRECATED - This server will be removed on 2025-12-20. Please migrate to alternative-server.'
      })
    });
    ```
  </Accordion>

  <Accordion title="Export Data First" icon="download">
    Save a local copy of your server metadata before deleting:

    ```python
    import json
    import requests
    import os

    server_name = "my-test-server"
    headers = {'Authorization': f'Bearer {os.getenv("SUPERBOX_API_TOKEN")}'}

    # Get server details
    response = requests.get(
        f'https://api.superbox.ai/api/v1/servers/{server_name}',
        headers=headers
    )
    server_data = response.json()['server']

    # Save to file
    with open(f'{server_name}_backup.json', 'w') as f:
        json.dump(server_data, f, indent=2)

    print(f"Data saved to {server_name}_backup.json")
    ```
  </Accordion>

  <Accordion title="Notify Users" icon="bell">
    Consider notifying your users before deletion:

    - Post an announcement on your homepage
    - Update your README with a deprecation notice
    - Suggest alternative servers
  </Accordion>
</AccordionGroup>
